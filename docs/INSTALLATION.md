# Установка и восстановление

## Первый запуск

```sh
curl -fsSL https://raw.githubusercontent.com/Lfyz-git/Stolas/v0.4.0/bootstrap.sh | sh -s -- --dir /opt/stolas
```

Запускайте от обычного пользователя с доступом к каталогу. Если `/opt/stolas`
ещё нет, администратор может создать его заранее:

```sh
sudo install -d -o "$USER" -g "$(id -gn)" /opt/stolas
```

Загрузчик проверяет SHA-256 архива релиза, затем открывает мастер.
`--ref` выбирает другой релиз. Для ветки или полного SHA дополнительно нужен
`--sha256` доверенной копии архива. Проверка суммы выявляет повреждение;
это не отдельная подпись издателя. Можно сначала скачать и изучить bootstrap.

`--configure-only` сохраняет настройки без Docker и теста.
Если Python отсутствует, его установка требует отдельного согласия до мастера.
До итогового подтверждения Docker, firewall, маршруты и сервисы не меняются.

## После прерывания

Повторите команду установки с `--action reconfigure`.
Черновик хранит завершённые шаги; продолжение предлагается отдельно от начала заново.
Ctrl+C сохраняет черновик, `:cancel` удаляет его и отменяет применение.
Секреты старой интеграции v0.3.0 не переносятся в Core и не запрашиваются заново.
Если файл не был сохранён старой версией до прерывания, восстановить его значения нельзя.

Не удаляйте каталог рекурсивно. Посторонние файлы установщик не перезаписывает.
После выполненного первичного теста продолжение незавершённой установки не
запускает его повторно. Неудачная проверка WAN завершает установку кодом 2:
агент установлен, но измерение требует внимания.

## Обновить

```sh
curl -fsSL https://raw.githubusercontent.com/Lfyz-git/Stolas/v0.4.0/bootstrap.sh | sh -s -- --dir /opt/stolas --action update
```

Обновление сохраняет `.env`, конфигурацию, SQLite volume и существующие workflow.
Дополнительный нагрузочный тест не выполняется. Изменение исходников защищено
блокировкой, журналом транзакции и резервной копией. При ошибке предусмотрено
восстановление. Для старого неподтверждённого черновика используется новый мастер.

## Откатить исходники

```sh
sh install.sh --action rollback
```

Нужна резервная копия предыдущей установленной версии. Локальные настройки
и данные не удаляются. После отката ниже v0.4.0 возвращается прежний интерфейс;
новая отдельная интеграция может отсутствовать. Не включайте workflow до Manual test.

## Диагностика без изменений

```sh
sh install.sh --diagnose
```

JSON содержит обнаруженные компоненты, версии, интерфейсы и этапы установки,
без секретов. Пакеты, контейнеры и конфигурация не меняются.
Для диагностики без локальных исходников bootstrap поддерживает `--diagnose`.

Коды установщика: 0 — завершено, 1 — ошибка, 2 — агент установлен, измерение
недоступно, 3 — отмена мастера, 130 — прерывание. Повторная настройка с изменением
параметров запускает новый тест; update и rollback — только проверку готовности.
