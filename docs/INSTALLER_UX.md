# Установщик v0.4.0

## Что изменилось

| Проблема v0.3.0 | Решение |
| --- | --- |
| Установка зависит от n8n/Telegram | Core устанавливается отдельно; интеграция — отдельная команда |
| Обязательный Bot Token и дубликаты credentials | Telegram секреты остаются в n8n; выбираются существующие ID |
| Вопросы с required/off, смешанные с пояснениями | Отдельные смысловые блоки, человеческие варианты, отдельный ввод |
| Нет читаемой структуры и цвета | Четыре этапа, отступы, сдержанная ANSI-палитра |
| Нужно проходить весь опрос для исправления поля | Из сводки открывается нужный раздел |
| Ошибка интеграции мешает завершить установку | Жизненные циклы Core и клиентов разделены |
| Старые черновики требуют устаревшие секреты | Миграция оставляет только проверенные параметры Core |
| Нет операционных событий | Стандартные JSON Lines без внешних зависимостей |

Обнаружение → проверка → предложение → подтверждение → применение → проверка
сохраняется. Обычный путь после выбора каталога — **три ответа**:
режим проверки канала, разрешённый IP и подтверждение.

## Какие вопросы остались

A — обнаруживаемый факт, B — безопасное значение по умолчанию,
C — решение пользователя, D — информация, которую нельзя достоверно угадать.

| Параметр | Категория | Поведение |
| --- | --- | --- |
| ОС, Docker, Compose, инструменты, интерфейсы, версия/этап установки | A | Автоматическое обнаружение; подробности в --diagnose |
| Каталог и повторная настройка/обновление/откат | C | --dir/--action либо короткий выбор |
| Имя узла, измерительные параметры, порт, log level | A/B | Defaults/сохранённые значения; изменение из сводки или файла |
| Токен Stolas | B | Генерируется автоматически, не показывается |
| Проверять ли основной канал | C | Человеческие Да/Нет, без внутренних имён |
| Разрешённый внешний IPv4/CIDR | D | Отдельный ввод после включения проверки; нет угадывания по текущему IP |
| Группы серверов, порядок, пороги | B/C | Существующие значения; расширенная настройка |
| Доступ API из сети | C | Явный выбор доверенной сети и обнаруженного адреса |
| n8n, расписание, chat ID, credentials | C/D | Полностью убраны из основного мастера |
| Telegram Bot Token | — | Stolas не запрашивает и не хранит |
| Ключ API n8n | D | Только отдельный мастер автоматического подключения, только в памяти |

## Навигация и совместимость

`:back` возвращает назад; из сводки можно исправить отдельный раздел.
`:rescan` обновляет обнаружение. `:cancel` отменяет до применения и удаляет
черновик; Ctrl+C сохраняет завершённые шаги для повторного запуска.

ANSI-акценты включаются в TTY с подходящим TERM: голубой — этап/ввод,
зелёный — успех, жёлтый — предупреждение, красный — ошибка.
`NO_COLOR`, `TERM=dumb`, отсутствие TTY/ANSI сохраняют тот же текст без цвета.
Длинные значения переносятся; навигация работает при вставке значений.

Реальный Linux PTY-тест в CI проверяет 80 колонок, ошибочный ввод,
возврат назад, пустые строки и ANSI. Артефакт `installer-terminal` содержит
сырой вывод реального псевдотерминала; SVG выше воспроизводится той же фикстурой.

Блокировка установщика, приватные файлы, проверка WAN, nonroot-контейнер,
checksum архива, резервные копии и восстановление сохранены.
Сети Docker, firewall, proxy и сторонние контейнеры автоматически не меняются.
