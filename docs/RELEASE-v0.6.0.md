# Stolas v0.6.0

Новая базовая версия проекта с отдельной Git-историей и документированными
синтетическими данными для примеров и тестов.

## Возможности

- Измерения IPv4 TCP через iperf3, история SQLite и HTTP API.
- Установка и управление Docker runtime: обновление, восстановление и удаление
  с сохранением конфигурации и истории.
- Проверка основного интернет-канала, группы серверов и резервные проверки.
- Интеграция n8n: уведомления, суточные отчёты и использование существующих credentials.
- Запросы к сервисам определения внешнего IP содержат User-Agent Stolas/<version>.
- Проверка данных для публикации, включая вложенные тестовые архивы, добавлена в CI.

## Обновление

В существующей установке:

```sh
stolas update
```

Если команда ещё не добавлена в PATH, из каталога установки:

```sh
sh ./stolas update
```

Проверены миграции установок v0.4.0 и v0.5.0, сохранение SQLite, откат и повторное
обновление. Архив `stolas-v0.6.0.tar.gz` и `SHA256SUMS` используются штатным
загрузчиком. Контрольная сумма подтверждает целостность архива, не подпись издателя.

## Проверки

Полная локальная Linux/Docker-матрица: 255 Python-тестов без пропусков,
Docker-миграции и сети, sudo, iperf3, API и импорт n8n, Alloy, Compose,
сборка и runtime-тесты production image. Перед выпуском матрица повторяется
в GitHub Actions. Подробности и ограничения: [VALIDATION.md](../VALIDATION.md).
