# Stolas v0.5.1

- #9: чистая установка без Docker находит `install-docker.sh` внутри
  `.stolas/installer`, после итогового подтверждения. Отсутствующий Python
  проверен отдельным сценарием shell bootstrap до создания runtime.
- #9: предупреждение об отсутствии прямых прав на Docker видно до применения
  и в diagnose, включая успешное обнаружение через sudo. Права и группы
  автоматически не меняются.
- #10: необязательная команда из любого каталога, пользовательский и системный
  варианты, выбор имени при конфликте. Обёртка содержит абсолютный путь,
  без секретов и изменений профиля оболочки.
- Ownership обёртки сохраняется при update/rollback. Оба режима uninstall
  удаляют только собственную неизменённую команду; изменённая сохраняется.
  При откате Core до поддержки PATH сохраняется текущий инструмент управления.

Обновление v0.5.0: `/opt/stolas/stolas update --version v0.5.1`.
Если команда ещё не настроена: `/opt/stolas/stolas command install`.
Без PATH работает локальный `./stolas`.

Проверки и ограничения: [VALIDATION.md](../VALIDATION.md). Реальная установка
пакетов apt на чистом Ubuntu/Debian и развёртывание на Azazel не заявляются.
