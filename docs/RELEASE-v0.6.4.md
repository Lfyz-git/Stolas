# Stolas v0.6.4

После успешной фиксации обновления Stolas явно сообщает результат и установленную
версию Core. Ошибки и прерывания не выдаются за успешное обновление.

Отчёт о точках восстановления вынесен в отдельный краткий раздел. Он показывает
сохранённые точки и, если удаление действительно состоялось, число удалённых
устаревших точек за текущую операцию. Нулевые показатели, внутренние лимиты и
служебные категории скрыты. Длинного предупреждения с предложением повторить
успешное обновление больше нет. Отступы сохраняются и в узком терминале.

Неоднозначные старые точки по-прежнему сохраняются. Отчёт предлагает удалять их
вручную только после проверки необходимости. Незавершённые или повреждённые
точки требуют отдельной проверки; рекомендация удалить их не выдаётся.
Правила безопасной очистки и расположение файлов остались прежними.

Новая команда `stolas version` показывает установленную версию Core, например
`Stolas Core v0.6.4`, без сети и работающего Docker. Используются локальные
метаданные; версия инструмента управления не подменяет версию Core после отката.
При отсутствии подтверждённых сведений команда сообщает об этом и возвращает
код 1. Команда включена в `stolas help`; параметр `stolas update --version`
по-прежнему независимо выбирает версию для обновления.

Обновление: `stolas update`. Настройки и история сохраняются.
