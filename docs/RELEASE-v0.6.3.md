# Stolas v0.6.3

Перенастройка больше не зависит от запуска измерения скорости. `stolas configure`
проверяет настройки, пересоздаёт сервис и проверяет авторизованный API, затем
фиксирует транзакцию. Cooldown, занятая блокировка измерения и недоступность
внешнего iperf3 не мешают сохранить здоровую конфигурацию. Для отдельного теста
используйте `stolas run`. Первичная установка сохраняет прежнее поведение;
`--configure-only` по-прежнему только записывает настройки без запуска Docker.
Ошибки валидации, запуска контейнера и API остаются ошибками с безопасным откатом.

Очистка резервных копий сохраняет до трёх обычных пригодных точек восстановления,
включая завершённую копию, на которую ссылается текущий журнал отката. Старые
снимки сверяются с текущим журналом, журналами в проверенном инвентаре снимков
и сохранёнными свидетельствами предыдущей транзакции. Подтверждённый статус
записывается до замены журнала и сохраняется для следующих операций.

Незавершённые, неизвестные и повреждённые снимки сохраняются как явные исключения.
По возрасту или `configured=true` завершение не определяется. При отсутствии
подтверждения, ошибках доступа или невозможности безопасного удаления фактическое
число каталогов может превышать три. Один отчёт за операцию показывает количества,
причины и дальнейшие действия без содержимого конфигурации и приватных путей.
После неуспешной или отменённой операции и при явном откате удаления не выполняются.
Ссылки, переходы за пределы каталога транзакций и специальные файлы отклоняются.
SQLite, Docker volumes, резервные копии настроек и посторонние файлы не удаляются.

Обновление: `stolas update`. Конфигурация и история сохраняются.
