# Stolas v0.6.1

Исправлен ложный `route_verification_unavailable` при медленном запуске Python:
проверки внешнего IP больше не запускают отдельный интерпретатор для каждого
источника. Исправление issue #1.

Вся проверка WAN остаётся в изолированном процессе с жёстким общим сроком,
включающим запуск Python, поиск маршрута и запросы. Каждый HTTPS-источник
проверяется в потоке с отдельным сроком: зависший DNS или ответ не мешает перейти
к резервному источнику. Завершение процесса прекращает оставшиеся потоки.

Значения `source_timeout` и `verification_timeout` по умолчанию не увеличены.
Сохранены прямой выход без прокси, запрет редиректов, User-Agent, ограничения
ответа, проверка IPv4 и разрешённых CIDR, а также блокировка измерений при
несовпадении WAN или отсутствии подтверждений.

Регрессионные тесты воспроизводят медленный запуск интерпретатора, быстрый
HTTPS-ответ, зависший DNS, резервный источник после таймаута, общий срок и полный
локальный цикл download/upload с реальным iperf3 и включённым WAN guard.

Обновление существующей установки:

```sh
stolas update
```

Без команды в PATH, из каталога установки: `sh ./stolas update`.
В релизе доступны `stolas-v0.6.1.tar.gz` и `SHA256SUMS` для штатного загрузчика.
